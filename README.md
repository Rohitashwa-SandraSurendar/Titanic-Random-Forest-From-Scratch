## Requirements

- Python 3.x
- Google Colab or Jupyter Notebook

Required Python libraries:

- NumPy
- Pandas
- Matplotlib
- Seaborn

## Running the Project

1. Clone or download this repository.
2. Ensure the folder structure remains unchanged.
3. Open `Titanic_ACM_Project.ipynb` in Google Colab or Jupyter Notebook.
4. Run all cells from top to bottom.

The notebook expects the datasets to be located at:

```python
data/train.csv
data/test.csv
```

No additional setup is required.

## Notes

- The Decision Tree and Random Forest are implemented entirely from scratch.
- No pre-built machine learning models (e.g. `sklearn.tree.DecisionTreeClassifier` or `sklearn.ensemble.RandomForestClassifier`) are used.
